# Solinea Hub

Solinea Hub ist ein CRM-System für Freelancer und kleine Unternehmen.

## Features

- Kundenverwaltung
- Projektverwaltung
- Anfrageverwaltung
- Dashboard mit Kennzahlen
- Authentifizierung
- PostgreSQL Datenbank
- Deployment über Vercel

## Technologien

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Vercel

## Installation

```bash
npm install
npm run dev
